Paper formula · index-based scheduling
Index formula used: Inm(A, ν) = νm−1 + A − γn*. The score matrix below is calculated using this expression. Servers are ordered by increasing cost to determine the preceding-server cost νm−1; for the first server, the predecessor cost is taken as 0. Set γ* in the controls. This implements the paper's stated index-formula case, not the complete MDP solver.
